🍔 Foodie Cart – Food Ordering & Cart Management App

A Python-based food ordering application built with Streamlit. Foodie Cart allows users to explore food items, add products to their cart, manage quantities, calculate order totals and download order details.

🚀 Project Overview

Foodie Cart is a simple and interactive food ordering application designed to demonstrate the core functionality of an online shopping cart.

Users can browse food items, add custom dishes, manage their orders and view their order activity through an easy-to-use interface.

✨ Features

- Browse food items with images and prices.
- Add food items to the shopping cart.
- Increase or decrease item quantities.
- Add custom food items with custom prices.
- Calculate total order amount automatically.
- Search for items in the current cart.
- Remove individual items or clear the cart.
- View order activity history.
- Download order details in CSV format.
- Responsive layout using Streamlit.

🛠️ Technologies Used

Technology| Purpose

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/devparkash2004/Foodie-Cart.git

2. Open the project folder

cd Foodie-Cart

3. Create a virtual environment

python -m venv venv

Activate it:

Windows:

venv\Scripts\activate

Mac/Linux:

source venv/bin/activate

4. Install dependencies

pip install -r requirements.txt

5. Run the application

streamlit run app.py

The application will open in your browser.
